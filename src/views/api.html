🏪 API Sistema de Ferretería

Documentación interactiva de todos los endpoints disponibles

Categorías Proveedores Clientes Usuarios Productos Ventas Detalles de Venta

📝 Información Importante

  • Base URL: http://localhost:3000
  • Formato de respuesta: JSON
  • Estado del servidor: Verificando...

📁 Categorías

GET /api/categorias

Obtener todas las categorías

GET /api/categorias/:id

Obtener una categoría por ID

Ejemplo:

GET /api/categorias/1
POST /api/categorias

Crear nueva categoría

Body:

{ "nombre": "Herramientas manuales", "descripcion": "Herramientas de mano para construcción y hogar" }
PUT /api/categorias/:id

Actualizar categoría

DELETE /api/categorias/:id

Eliminar categoría

🏢 Proveedores

GET /api/proveedores

Obtener todos los proveedores

GET /api/proveedores/search?nombre=Juan

Buscar proveedor por nombre

POST /api/proveedores

Crear nuevo proveedor

Body:

{ "nombre": "Constructora Pérez", "contacto": "Juan Pérez", "telefono": "555-0101", "email": "juan@perez.com", "direccion": "Av. Industrial 123" }
PUT /api/proveedores/:id

Actualizar proveedor

DELETE /api/proveedores/:id

Eliminar proveedor

👥 Clientes

GET /api/clientes

Obtener todos los clientes

GET /api/clientes/search?termino=Juan

Buscar cliente por nombre, apellido o DNI

GET /api/clientes/dni/:dni

Obtener cliente por DNI

POST /api/clientes

Crear nuevo cliente

Body:

{ "nombre": "José", "apellido": "Martínez", "dni": "12345678", "telefono": "555-0201", "email": "jose.martinez@email.com", "direccion": "Calle Principal 1" }
PUT /api/clientes/:id

Actualizar cliente

DELETE /api/clientes/:id

Eliminar cliente

👤 Usuarios

GET /api/usuarios

Obtener todos los usuarios (sin password)

POST /api/usuarios

Crear nuevo usuario

Body:

{ "username": "admin", "password": "admin123", "nombre": "Administrador Principal", "email": "admin@ferreteria.com", "rol": "admin", "activo": true }
PUT /api/usuarios/:id

Actualizar usuario

DELETE /api/usuarios/:id

Eliminar usuario

PUT /api/usuarios/:id/password

Cambiar password

📦 Productos

GET /api/productos

Obtener todos los productos

GET /api/productos/search?termino=Hammer

Buscar productos

GET /api/productos/lowstock

Obtener productos con stock bajo

GET /api/productos/categoria/:idCategoria

Obtener productos por categoría

POST /api/productos

Crear nuevo producto

PUT /api/productos/:id

Actualizar producto

DELETE /api/productos/:id

Eliminar producto (soft delete)

💰 Ventas

GET /api/ventas

Obtener todas las ventas

GET /api/ventas/:id

Obtener venta con detalles

GET /api/ventas/fecha?fechaInicio=2025-01-01&fechaFin=2026-12-31

Obtener ventas por fecha

GET /api/ventas/today

Obtener ventas del día

GET /api/ventas/summary?fechaInicio=2025-01-01&fechaFin=2026-12-31

Obtener resumen de ventas

POST /api/ventas

Crear nueva venta

Body:

{ "id_cliente": 1, "metodo_pago": "efectivo", "descuento": 0, "detalles": [ { "id_producto": 1, "cantidad": 2 }, { "id_producto": 3, "cantidad": 1 } ] }

📋 Detalles de Venta

GET /api/venta-detalles/:idVenta

Obtener detalles de una venta

GET /api/venta-detalles/producto/:idProducto

Obtener historial de ventas de un producto

GET /api/venta-detalles/top?limit=10

Obtener productos más vendidos
